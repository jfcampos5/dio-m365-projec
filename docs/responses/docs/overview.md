# Visão Geral do Projeto – Microsoft Graph + IA (Bootcamp Caixa – DIO + Microsoft)

Este repositório documenta os experimentos, consultas e aprendizados desenvolvidos durante o **Bootcamp Caixa – Inteligência Artificial na Prática**, uma parceria entre **CAIXA**, **Microsoft** e **DIO**.  
O objetivo deste projeto é registrar o uso do **Microsoft Graph**, demonstrar consultas reais, armazenar respostas da API e consolidar o aprendizado sobre Inteligência Artificial integrada ao Microsoft 365.

---

## 📌 Objetivo do Repositório

- Demonstrar domínio básico do uso do **Microsoft Graph Explorer**  
- Documentar cada requisição realizada  
- Criar um histórico de respostas da API para referência futura  
- Consolidar práticas de versionamento com Git e GitHub  
- Criar uma base sólida para projetos futuros com IA + Microsoft 365  

---

## 🧪 Consultas realizadas no Microsoft Graph

As principais consultas feitas no **Graph Explorer** foram:

- `GET /me` – informações básicas da conta  
- `GET /beta/me/profile` – detalhes completos do perfil  
- `GET /me/messages` – mensagens de e-mail  
- `GET /me/mailFolders` – pastas de e-mail  
- `GET /me/photo` – foto do perfil  
- `GET /me/drive/root/children` – arquivos armazenados no OneDrive  


Cada arquivo foi salvo no formato JSON seguindo boas práticas.
