# dio-m365-project

Projeto criado durante o **Bootcamp CAIXA - Inteligência Artificial na Prática - DIO + Microsoft** sobre **Inteligência Artificial e Microsoft 365**.

## 🎯 Objetivo
Explorar e documentar práticas de desenvolvimento com:
- Microsoft Graph API
- Copilot para Microsoft 365
- Integrações com Teams e SharePoint
- Conceitos de Inteligência Artificial aplicados ao Microsoft 365

## 🛠️ Tecnologias utilizadas
- Microsoft 365 Developer Program (Sandbox E5)
- Microsoft Graph Explorer
- GitHub (versionamento e documentação)
- Power Platform (Power Automate, Power Apps)
- Copilot para Microsoft 365

## 🔎 Consultas realizadas no Graph Explorer
- `GET /me` → informações básicas da conta
- `GET /beta/me/profile` → perfil detalhado
- `GET /me/mailFolders` → pastas de e-mail
- `GET /me/events` → eventos de calendário

Os resultados dessas consultas estão documentados na pasta `docs/responses/`.

## 📚 Aprendizados do Bootcamp
- Como usar o Graph Explorer para consumir APIs do Microsoft 365
- Como documentar projetos no GitHub
- Como integrar Copilot e Inteligência Artificial em soluções reais
- Como se qualificar para a sandbox E5 do Microsoft 365 Developer Program
